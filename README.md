# FinEdge

## About

FinEdge is a personal finance & expense tracker API
This repository contains the core application code, configuration, and developer tooling needed to run the project locally.

## Tech Stack

- **Runtime:** Node.js (LTS)
- **Package Manager:** npm
- **Framework:** Express.js
<!-- - **Database:** Mongodb -->
<!-- - **Environment Config:** `.env` file -->

## Prerequisites

Install the following before setup:

- Node.js (v18+ recommended)
- npm (comes with Node.js)
- Git

## Setup Instructions

1. **Clone the repository**
  ```bash
  git clone git@github.com:Mak2503/fin-edge.git
  cd fin-edge
  ```

2. **Install dependencies**
  ```bash
  npm install
  ```
